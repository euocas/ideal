> Sistema web desenvolvido para a **IDEAL**, reunindo uma interface moderna, funcionalidades administrativas e recursos para gerenciamento de informações.

O projeto foi desenvolvido como uma aplicação web completa, envolvendo **UI/UX, Front-End e desenvolvimento Back-End**, com foco em organização, usabilidade e uma experiência consistente para os usuários.

## Sobre o projeto

O **IDEAL** nasceu como um projeto colaborativo desenvolvido para transformar uma proposta de interface e identidade visual em uma aplicação web funcional.

Além da criação da interface, o projeto envolve a implementação das funcionalidades do sistema, integração com banco de dados, gerenciamento de informações e recursos para geração e manipulação de documentos.

O projeto também fez parte do meu processo de evolução em **Design UI/UX e desenvolvimento Front-End**, permitindo trabalhar desde a concepção visual até a implementação da aplicação.

## Instalação

### 1. Clone o repositório

```bash
git clone https://github.com/euocas/ideal.git
```

### 2. Acesse a pasta

```bash
cd ideal
```

### 3. Instale as dependências

```bash
composer install
```

### 4. Configure as variáveis de ambiente

Crie um arquivo `.env` na raiz do projeto e configure as informações necessárias para o ambiente local, como conexão com banco de dados e serviços de e-mail.

Exemplo:

```env
APP_ENV=local

DB_HOST=localhost
DB_NAME=nome_do_banco
DB_USER=usuario
DB_PASS=senha
```

> As variáveis necessárias podem variar de acordo com a configuração do ambiente.

### 5. Configure o banco de dados

Execute os scripts disponíveis na pasta:

```text
script_bd/
```

Configure o banco de dados de acordo com o ambiente de desenvolvimento.

### 6. Execute o projeto

Configure o servidor local para apontar para a pasta pública da aplicação e acesse o projeto pelo navegador.

## Desenvolvimento

O projeto utiliza o Composer para gerenciamento das dependências PHP.

Para adicionar ou atualizar dependências:

```bash
composer update
```

Para instalar as dependências exatamente nas versões definidas pelo projeto:

```bash
composer install
```
